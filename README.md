# Examen práctico

## Objetivo

Desplegar una pequeña aplicación web mediante contenedores,
administrar el proyecto con Git y GitHub, y crear una visualización
de datos.

## Imagen utilizada

examen:TU_MATRICULA

## Puertos

- 8081
- 8082
- 8083

## Cómo levantar los servicios

Ejecutar:

docker compose up -d

Para comprobar los servicios:

docker compose ps

La aplicación puede consultarse mediante:

- http://localhost:8081
- http://localhost:8082
- http://localhost:8083
